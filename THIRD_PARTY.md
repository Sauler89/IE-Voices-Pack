# Third-party content and licensing notes

IE-Voices-Pack combines material originating from several independent Infinity Engine voice-pack projects.

## Important

There is **no single blanket license** that can be applied to every file in the compilation.

- Original game audio and game text remain copyrighted material belonging to their respective rights holders.
- Source-project code retains the license, permissions, and attribution requirements of the project from which it originated.
- The NWN2 Soundsets project explicitly licenses its **TP2 code only** under CC BY 4.0; its game audio, images, and game text are not covered by that code license.
- GraionDilach's source projects identify themselves as unofficial fan content and preserve rights-holder notices.
- IE-Voices-Pack does not claim ownership of or relicense third-party game assets.
