# IE-Voices-Pack

**Version 1.2.0**

IE-Voices-Pack is a unified WeiDU collection of **188 English player voice sets** for modern Infinity Engine Enhanced Edition games.

## Included voice sets

- Baldur's Gate: 18 base voice sets
- Baldur's Gate II: 9 base voice sets
- Baldur's Gate NPCs: 36 voice sets
- Icewind Dale / Heart of Winter: 30 voice sets
- Icewind Dale II: 12 voice sets
- Planescape: Torment: 8 character voice sets
- Neverwinter Nights: 59 voice sets
- Neverwinter Nights 2 / Mask of the Betrayer / Darkness over Daggerford: 16 named character voice sets

**Total: 188 voice sets.**

The 14 generic NWN2 sets named Female 1–7 and Male 1–7 are intentionally omitted. The 16 named NWN2/MotB/DoD characters are installed through one **NWN2 Voice Pack** component.

## Compatibility

Intended for:

- Baldur's Gate: Enhanced Edition 2.6.6+
- Baldur's Gate II: Enhanced Edition 2.6.6+
- Enhanced Edition Trilogy (EET) on compatible 2.6.6+ games
- Icewind Dale: Enhanced Edition 2.6.6+

Classic Icewind Dale II and Planescape: Torment: Enhanced Edition are not supported target games.

On Steam/GOG Baldur's Gate: Enhanced Edition installations with Siege of Dragonspear packaged as DLC, run **DlcMerger** before installing WeiDU mods.

## Installation

1. Extract both `setup-allvoices.exe` and the `allvoices` folder into the game directory containing `chitin.key`.
2. Run `setup-allvoices.exe`.
3. Select the desired components.
4. Run the same installer again whenever you want to change or uninstall components.

The installer interface is **English-only** in v1.2.0.

### Why are the installer and folder still named "allvoices"?

`allvoices` is the internal WeiDU technical identifier used by earlier releases. It is intentionally preserved so existing v1.0.0/v1.1.0 installations can be upgraded, changed, or uninstalled safely. The public project and release name is **IE-Voices-Pack**.

## Upgrading from v1.1.0

Extract v1.2.0 over the existing installation and run `setup-allvoices.exe`. Keeping the same internal WeiDU identifier preserves component history and upgrade compatibility.

## Conflicts

Do not install the same voice content from both IE-Voices-Pack and the corresponding standalone voice-pack mod. The installer blocks duplicate installations that it can detect.
