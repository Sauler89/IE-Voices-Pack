# Changelog

## v1.1.0

- Unified **188 English player voice sets** in a single WeiDU package.
- Includes voice sets originating from Baldur's Gate, Baldur's Gate II, Icewind Dale, Icewind Dale II, Planescape: Torment, Neverwinter Nights, Neverwinter Nights 2, Mask of the Betrayer, and Darkness over Daggerford.
- Includes 16 named NWN2 / MotB / Darkness over Daggerford soundsets.
- Intentionally excludes the 14 generic NWN2 Female 1–7 and Male 1–7 sets.
- Public repository documentation standardized in English under the **IE-Voices-Pack** project name.
- Added detailed source credits and third-party licensing notes.
