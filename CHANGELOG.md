# Changelog

## v1.2.0

- Public project name standardized as **IE-Voices-Pack**.
- Release package converted to English-only documentation and installer language.
- Removed the legacy Italian README and Italian installer translation.
- Replaced remaining public-facing references to **Infinity Engine All Voices** with **IE-Voices-Pack**.
- Added detailed credits and third-party notices to the release package.
- Preserved the internal WeiDU technical identifier `allvoices` and `setup-allvoices.exe` for upgrade/uninstall compatibility with earlier releases.
- Preserved all 6,742 bundled WAV files unchanged.
- Includes the same **188 English player voice sets** as v1.1.0.

## v1.1.0

- Unified **188 English player voice sets** in a single WeiDU package.
- Includes voice sets originating from Baldur's Gate, Baldur's Gate II, Icewind Dale, Icewind Dale II, Planescape: Torment, Neverwinter Nights, Neverwinter Nights 2, Mask of the Betrayer, and Darkness over Daggerford.
- Includes 16 named NWN2 / MotB / Darkness over Daggerford soundsets.
- Intentionally excludes the 14 generic NWN2 Female 1–7 and Male 1–7 sets.
