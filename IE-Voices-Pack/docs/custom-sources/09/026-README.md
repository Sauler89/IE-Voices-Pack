# Gromnir voice curation catalog

Open `catalog.html` locally in a web browser. Play the original recordings and the full sources for the manual cut requests, then type your decisions into the note fields. The suggestions are not final assignments.

Notes are saved in this browser and the page shows a visible status for successful or failed persistence. The optional `Chriz: ...` convention makes personal comments easy to recognize. **Export notes** creates `gromnir-notes.csv`; return that CSV for the next curation round. **Reset notes** asks for confirmation and removes the notes saved by this catalog from the current browser.

This handoff contains 13 original recordings and 3 manual cut requests. `GROM01-GROM06` have CRE-authoritative events. The prior machine timings were rejected: play each untouched full source and cut by ear in Audacity. A human-made cut must replace each request before any slot assignment is accepted.

The slot ledger shows all 63 playable-character sound slots. `damage2` and `damage3` are disabled because those BG2:EE v2.6 slots are unsafe. No game installation has occurred, and this catalog is not a finished voice pack or installer.
